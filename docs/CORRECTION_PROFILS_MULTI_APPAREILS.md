# Profils communs sur tous les appareils

Depuis Série 1.1, la liste des profils n’est plus locale au navigateur.

- Un profil créé et synchronisé apparaît automatiquement sur le site, la PWA et les autres appareils.
- La première ouverture demande son code à 4 chiffres.
- L’appareil mémorise ensuite l’accès.
- Le bouton `Verrouiller sur cet appareil` efface uniquement cet accès mémorisé.
- Le profil reste visible dans la liste commune.
- `Supprimer partout` efface réellement le profil et ses données.

Il n’est plus nécessaire de copier un lien personnel entre appareils.
