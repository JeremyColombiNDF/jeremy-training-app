# Guide utilisateur — version 0.1

## Pendant la semaine

1. Ouvrir l'écran `Semaine`.
2. Saisir le poids du matin.
3. Ouvrir la séance du jour.
4. Pour chaque exercice :
   - laisser les valeurs prévues si elles ont été respectées ;
   - modifier uniquement la charge, les répétitions ou les séries différentes ;
   - renseigner le RPE ;
   - sélectionner un statut et les problèmes éventuels ;
   - valider l'exercice.
5. Terminer la séance et renseigner sa difficulté globale.

## En fin de semaine

1. Ouvrir l'écran `Bilan`.
2. Compléter sommeil, énergie, faim, protéines, pas, cardio et ressenti.
3. Cliquer sur `Copier le bilan`.
4. Coller le texte dans le chat sportif ChatGPT.

## Importer la semaine suivante

1. Copier le bloc compris entre `SPORT_APP_IMPORT_START` et `SPORT_APP_IMPORT_END` dans la réponse de ChatGPT.
2. Ouvrir `Données` dans l'application.
3. Coller le bloc dans la zone d'import.
4. Cliquer sur `Vérifier et importer`.

## Sauvegarde

La version 0.1 utilise le stockage local du navigateur. Télécharger régulièrement une sauvegarde depuis l'écran `Données`, notamment avant de vider l'historique du navigateur ou de changer de téléphone.
