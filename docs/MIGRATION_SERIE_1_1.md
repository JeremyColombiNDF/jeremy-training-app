# Migration Série 1.0 vers Série 1.1

## Avant la mise à jour

Dans chaque profil important, télécharger une sauvegarde depuis `Données > Maintenance`.

## Après le déploiement

Les anciens profils apparaissent dans le sélecteur avec la mention :

```text
À publier
```

Pour chacun des profils à conserver :

1. toucher le profil ;
2. choisir et confirmer un code personnel à 4 chiffres ;
3. toucher `Publier et synchroniser` ;
4. attendre l’ouverture du profil ;
5. vérifier le programme, les pesées et l’historique.

Le profil devient ensuite visible sur tous les appareils.

## Sur les autres appareils

1. actualiser la liste des profils ;
2. sélectionner le profil ;
3. saisir son code personnel ou le code administrateur ;
4. la version synchronisée est récupérée automatiquement.

## Doublons

Deux anciens profils portant le même nom mais ayant des identifiants différents restent séparés. Cela évite toute fusion dangereuse.

Après vérification, supprimer définitivement les profils de test ou doublons depuis `Gérer le profil actuel`.
